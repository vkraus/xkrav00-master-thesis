%%% Abstract (recommended range of about 150-250 words; this is not a thesis assignment)
\def\Abstrakt{%
Research shows that enterprises manage on average 83 different cybersecurity solutions from 29 vendors, making a consolidated and complete overview of enterprise security posture one of the most prevalent challenges. Data on threats, risks, assets, security controls, vulnerabilities, and incidents from these disparate tools must all be integrated to accurately assess security posture. This thesis presents Secubricks, a security analytics project built on Databricks platform that addresses these challenges through lakehouse architecture and standardized data models, providing a practical framework for security data analytics that's extensible, reusable, and fully agnostic to primary cybersecurity products and vendors.
}
